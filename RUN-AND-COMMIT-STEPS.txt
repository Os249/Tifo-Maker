PART 1 — LOOK AT IT
-------------------

Two PowerShell windows, both in the repo:

    cd C:\Users\PCD\Desktop\tifo-maker

Window 1:   npm run server
Window 2:   npm run dev

Open http://localhost:5173/ and press Match Day.


PART 2 — WHAT TO CHECK
----------------------

1. The section
   - The panel has a new "Accessories" section, right under Crowd.
   - Everything in it says Off. Nothing is burning when Match Day opens.

2. Levels
   - Drag Flares: Light (a handful at the front) -> Medium (a line along the
     front) -> Heavy (the lower half) -> Full (the whole stand). Each step
     adds fans. The ones already holding flares stay where they are.
   - Try Flags, Smoke bombs, Strobes, Paper & confetti and Phone lights the
     same way. Phone lights look best with Atmosphere -> Night.

3. Presets
   - Terrace, Ultras, Inferno and Light show set every slider at once, and
     the one in use is highlighted. All off puts everything out.

4. Where and colour
   - Where: North stand is the one the default camera faces. Try "The whole
     ground".
   - Flare colour Green, or Club colours. Smoke colour Red, Black, etc.

5. Sound (Sound section on)
   - Lighting flares hisses, and the crowd roars once. While they burn, a
     crackle stays under everything on the Effects fader. Put them out and it
     fades away.

6. Choreography
   - Cue type now has Flares on, Smoke bombs on, Strobes on, Flags up and
     Accessories off. Add "Flares on" at 0 s and press Play sequence. The
     flares light, and the Accessories slider moves to Medium by itself.
   - Also fixed: a cue at 0 s used to never fire (the auto show's opening
     whistle and drum had never sounded). They do now.

7. Arabic and phone
   - Switch to Arabic: الإكسسوارات, every label and level in Arabic.
   - On a phone the section fits the bottom sheet, with big sliders.


PART 3 — COMMIT
---------------

1. Stop both (Ctrl+C).

2. Prove it builds and passes:

       npm run build
       npm run verify

   The new browser suite needs the built app on port 8911:

       $env:PORT=8911; npm run server      (window 1)
       npm run test:accessories            (window 2)

3. Commit with the Summary and Description from the chat.

4. Pushing is yours. Railway deploys main.
