Tifo Maker — banners review: run it, then commit it
===================================================

Everything is already in C:\Users\PCD\Desktop\tifo-maker. Nothing to bundle,
nothing to download. Your main is at "Tifo Maker — banners rebuild"; all of
this is uncommitted on top of it.


PART 1 — LOOK AT IT (no commit, no build needed)
------------------------------------------------

1. Open PowerShell in the repo:

       cd C:\Users\PCD\Desktop\tifo-maker

2. Start the dev server:

       npm run dev

3. Open http://localhost:5173/ — that is the editor. Leave the terminal
   running; it recompiles as you edit.

4. OPTIONAL — only for save / account / community. In a SECOND terminal:

       npm run server


PART 2 — WHAT TO CHECK
----------------------

Banner view (the flag in the left rail):
  - The right-hand panel shows Stand, Across, Blocks, How many and Tier, and
    "Measures W × H m on this ground" — without opening Match Day.
  - "Show it in the stadium": the bowl opens beside the artboard, looking at
    the banner. Change the stand or the blocks and it follows.
  - Add a text and click it: Front / Back / Duplicate / Delete appear in the
    panel. Delete, Ctrl+Z, Ctrl+Y, Ctrl+D and the arrow keys act on the
    banner — not on the seat design behind it.
  - The pencil next to the banner's name in the top bar renames it.
  - Type "Hanging banner", Tier 2 on a two-tier ground: the artboard becomes
    the long strip between the tiers and the shape controls lock, saying why.
    Set Tier back to "Whole stand" and your own shape comes back.
  - Reveal: a stand banner offers "Unroll down the stand" or "Already up"; a
    hanging banner offers "Haul up on ropes" or "Already up". The seconds
    follow the size until you move the slider; "Use the real time" puts that
    back.
  - A brand-new banner is white cloth, not invisible.

Stadium view:
  - Camera -> "Your banner".
  - No seats coming through the fabric, on an empty stand as well.

Match Day ("See it on match day" at the bottom of the banner panel):
  - It opens looking at the banner, with the Banners section open.
  - Stand East puts it on East (it used to go to North).
  - Play: the scrub bar follows the reveal instead of jumping to the end.

Stadium panel (Stadium in the left rail):
  - The region filter says "Any region" and each stadium's details say
    "Region". Before this they printed "sp.anyRegion" and "sp.region".
  - Load The Jewel of Jeddah: the status bar at the bottom says "The Jewel of
    Jeddah", not "community-jewel-jeddah-62k".
  - Switch to Arabic: the stadium names, their details and the notice under
    them are Arabic, and the dropdown arrows no longer sit on the words.


PART 3 — COMMIT
---------------

Only when you are happy with what you saw.

1. Stop the dev server (Ctrl+C).

2. Delete the five retired banner files. I could not delete them from here,
   so I emptied them — the build passes while they are there — but they
   should go:

       Remove-Item scripts\banner-physics.mts
       Remove-Item src\core\bannerMigrate.ts
       Remove-Item src\render\simulator\bannerFit.ts
       Remove-Item src\render\simulator\cloth.ts
       Remove-Item src\render\simulator\standHeightfield.ts

   Optional, the same kind of leftover (the old Banner Studio; nothing uses
   it, it still compiles):

       Remove-Item src\ui\bannerStudio.ts

   GitHub Desktop lists them as deleted; they go in with the rest.

3. Prove it builds:

       npm run build
       npm run verify

   Optional, a few minutes:

       npm run sweep:banner

4. Commit. The message is in BANNERS-REBUILD-COMMIT.txt in this folder, with
   the Summary and the Description labelled separately — paste them into
   GitHub Desktop's two fields.

5. Pushing is yours. Pushing main runs CI, and Railway deploys main, so push
   after step 3 passes.
