Tifo Maker — banners: run it, then commit it
============================================

Everything is already in C:\Users\PCD\Desktop\tifo-maker. Nothing to bundle,
nothing to download. Your main is at "Banners: review the whole system, and
fix what a user would hit"; all of this is uncommitted on top of it.


PART 1 — LOOK AT IT (no commit, no build needed)
------------------------------------------------

1. Open PowerShell in the repo:

       cd C:\Users\PCD\Desktop\tifo-maker

2. Start the dev server:

       npm run dev

3. Open http://localhost:5173/ — that is the editor. Leave the terminal
   running; it recompiles as you edit.


PART 2 — WHAT TO CHECK
----------------------

The tifo you already have:
  - The white sheet the Banner view used to put on your North stand by
    itself is gone. A banner you drew on, coloured or moved is still there;
    if you do not want it, open the Banner view and delete it with the bin.

A brand-new tifo (easiest: a private window, or another browser):
  - Stadium view: no banner anywhere.
  - Banner view: "No banner in this tifo", with Stand banner and Hanging
    banner buttons. The Type / Size / Fabric bar is not there yet.

Make one:
  - Click Stand banner. The panel's Banners list shows it: its colour, its
    name, "Stand banner · North" and a "Show in stadium" button.
  - Click "Show in stadium": the Stadium view opens with the camera on it,
    and the status line says so.
  - Make a Hanging banner from the list's own button. Each row's
    "Show in stadium" goes to its own banner.
  - Delete both with the bin in the bar: back to "No banner in this tifo".
    Ctrl+Z brings the last one back.

Also:
  - Open a design from the Gallery: the banners of the tifo you were on do
    not come with it.
  - At 1366 or 1280 wide, after drawing anything: the header fits, and
    "Sign up" stays on one line. (Community and Gallery are in the U menu.)
  - On a phone (or a narrow window with ?editor=1): "Show in stadium" in the
    Paint sheet closes the sheet and shows the whole banner.


PART 3 — COMMIT
---------------

Only when you are happy with what you saw.

1. Stop the dev server (Ctrl+C).

2. If you have not yet: delete the five retired banner files. They are
   empty placeholders, so nothing breaks while they are there, but they
   should go:

       Remove-Item scripts\banner-physics.mts
       Remove-Item src\core\bannerMigrate.ts
       Remove-Item src\render\simulator\bannerFit.ts
       Remove-Item src\render\simulator\cloth.ts
       Remove-Item src\render\simulator\standHeightfield.ts

   Optional, the same kind of leftover:

       Remove-Item src\ui\bannerStudio.ts

3. Prove it builds:

       npm run build
       npm run verify

4. Commit. The message is in BANNERS-REBUILD-COMMIT.txt in this folder, with
   the Summary and the Description labelled separately — paste them into
   GitHub Desktop's two fields.

5. Pushing is yours. Pushing main runs CI, and Railway deploys main, so push
   after step 3 passes.
