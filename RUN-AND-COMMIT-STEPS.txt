Tifo Maker — banners: run it, then commit it
============================================

Everything is already in C:\Users\PCD\Desktop\tifo-maker. Nothing to bundle,
nothing to download. Your main is at "Banners: a tifo starts with none, and
each one has Show in stadium"; all of this is uncommitted on top of it.


PART 1 — LOOK AT IT
-------------------

Two PowerShell windows, both in the repo:

    cd C:\Users\PCD\Desktop\tifo-maker

Window 1, the server (it publishes the three showcase designs as it starts;
its log says "banner showcase: +3 added"):

    npm run server

Window 2, the editor:

    npm run dev

Then open http://localhost:5173/ for the editor and
http://localhost:5173/community for the community. Leave both running.


PART 2 — WHAT TO CHECK
----------------------

Do this in a private window, or clear the site's storage, so you are "new":

1. "Banners are here"
   - Open the editor. After a second a card appears just under the Banner
     tab, pointing at it: "Banners are here", with "Not now" and
     "Try banners".
   - "Not now", then reload: it does not come back.
   - In a fresh private window, press "Try banners": the Banner view opens
     and its tour starts.
   - On a first-ever visit, the start dialog comes first and the card
     appears after you close it, never on top of it.

2. The banner tour
   - The first time the Banner view opens, the tour runs. With no banner it
     has 4 steps; "Skip tour" or Escape ends it, and it does not come back.
   - Make a banner, then press "How banners work" in the Banners panel: the
     tour runs again and walks through the sheet, the tools, the list,
     placement and match day.
   - Arabic: the same, in Arabic, with the cards on the correct side.

3. Match Day
   - In the Banner view, press "See it on match day". It opens on the banner.
   - Drag across the picture, including right over the banner: the camera
     moves around, and the banner stays where it is. Scroll: it zooms.
   - To move the banner: click it once (an outline appears), then drag it.

4. The community
   - /community opens on three "Template · With banners" cards by
     @tifomaker.
   - Open each one: the 3D preview opens on its banner, and the camera bar
     has a flag button for each banner. The kop has two: "One club" (a
     see-through mesh) and "12".
   - Signed in, press Remix on one: the editor opens with its banners too.


PART 3 — COMMIT
---------------

Only when you are happy with what you saw.

1. Stop both (Ctrl+C in each window).

2. Still to do from last time: delete the five retired banner files. They are
   empty placeholders, so nothing breaks while they are there, but they
   should go:

       Remove-Item scripts\banner-physics.mts
       Remove-Item src\core\bannerMigrate.ts
       Remove-Item src\render\simulator\bannerFit.ts
       Remove-Item src\render\simulator\cloth.ts
       Remove-Item src\render\simulator\standHeightfield.ts

   Optional, the same kind of leftover:

       Remove-Item src\ui\bannerStudio.ts

3. Prove it builds:

       npm run build
       npm run verify

4. Commit. The message is in BANNERS-REBUILD-COMMIT.txt in this folder, with
   the Summary and the Description labelled separately — paste them into
   GitHub Desktop's two fields. There are four new files in this commit:
   src\ui\bannerTour.ts, src\ui\whatsNew.ts, scripts\generate-showcase.mts
   and server\data\showcase.jsonl — make sure all four are ticked.

5. Pushing is yours. Pushing main runs CI, and Railway deploys main, so push
   after step 3 passes. On the first deploy the server publishes the three
   showcase designs by itself (the log says "banner showcase: +3 added");
   after that it finds them by title and adds nothing.
